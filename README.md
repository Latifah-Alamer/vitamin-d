# فيتامين د ☀️ — تذكير أسبوعي لشخصين

موقع بسيط يرسل تنبيه كل جمعة: **لطيفة ٢:٣٠ العصر، وإبراهيم ١:٣٠ الظهر** (بتوقيت السعودية)، وكل شخص يسجّل إنه أخذ حبته، والثاني يشوف.
فيه كمان تذكير ثاني **٨ المساء** لمن ما سجّل (تقدرين تحذفين `netlify/functions/evening-reminder.mjs` لو ما تبينه).

## ١) ارفعيه على Netlify
السحب والإفلات (Netlify Drop) ما يشغّل الـ functions، فاستخدمي وحدة من الطريقتين:

**عن طريق GitHub (الأسهل):**
1. ارفعي المجلد كـ repo على GitHub.
2. في Netlify: Add new site ← Import an existing project ← اختاري الـ repo ← Deploy.
   (ما يحتاج build command، الإعدادات موجودة في `netlify.toml`).

**أو عن طريق Netlify CLI:**
```bash
npm install
npm install -g netlify-cli
netlify login
netlify deploy --prod
```

## ٢) مفاتيح التنبيهات (VAPID)
شغّلي هذا الأمر مرة وحدة في أي جهاز فيه Node:
```bash
npx web-push generate-vapid-keys
```
وانسخي الناتج في Netlify ← Site configuration ← Environment variables:

| الاسم | القيمة |
|---|---|
| `VAPID_PUBLIC_KEY` | Public Key |
| `VAPID_PRIVATE_KEY` | Private Key |
| `VAPID_SUBJECT` | `mailto:ايميلك@example.com` |

بعدها سوي Redeploy (Deploys ← Trigger deploy).

## ٣) الحسابات والاستخدام
1. كل شخص يفتح الرابط ويختار اسمه، وأول مرة يختار رمز دخول من ٤ أرقام. بعدها ما أحد يقدر يسجّل باسمه بدون الرمز.
   سجّلي حسابك، وأرسلي الرابط لإبراهيم عشان ينشئ حسابه بنفسه.
2. **آيفون:** لازم تفتحينه من Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية»، وبعدين تفتحينه من الأيقونة وتشغّلين التنبيهات (يحتاج iOS 16.4 أو أحدث).
   **أندرويد:** من Chrome، اضغطي «شغّل التنبيهات» ومن القائمة «إضافة إلى الشاشة الرئيسية».
3. بعد تفعيل التنبيهات يوصلك **تنبيه ترحيب بعد ٣ دقايق تقريباً**.

## ٤) التأكد إن التنبيه بيشتغل الجمعة
1. **تنبيه الترحيب:** يوصل بعد ٣ دقايق من تفعيل التنبيهات. إذا وصل والتطبيق مسكّر، فالمفاتيح والاشتراك والمهام المجدولة كلها شغالة.
2. **زر «تجربة التنبيه»:** يرسل تنبيه بعد دقيقة تقريباً. اقفلي الشاشة وانتظري.
3. **تشغيل تذكير الجمعة نفسه:** Netlify ← Logs & metrics ← Functions ← `friday-reminder` ← زر **Run now**. انتبهي إنه يرسل لكم الاثنين (إلا اللي سجّل هالأسبوع).
4. **السجل:** بنفس الصفحة يطلع سطر مثل `friday reminder sent: 2`، وتقدرين تشيكين عليه يوم الجمعة بعد ٢:٣٠.

## ملاحظات
- البيانات محفوظة في Netlify Blobs (مفعّلة تلقائياً، ما تحتاج إعداد).
- أوقات التذكير في `REMINDER_TIMES` داخل `netlify/lib/shared.mjs`. إذا غيرتيها، عدّلي جدول `friday-reminder.mjs` بنفس الساعات بتوقيت UTC (السعودية ناقص ٣).
- **النقاط:** الحبة بنقطة، وخلال ربع ساعة من تذكيرك نقطة زيادة. إذا تعادلتوا يفوز اللي مجموع تأخيره أقل.
- المهام المجدولة تشتغل بس على نسخة الـ production المنشورة.
- الاسمين (لطيفة وإبراهيم) مضبوطين مسبقاً في `netlify/lib/shared.mjs`.
- **نسيان الرمز:** من لوحة Netlify ← Blobs ← store اسمه `meta` ← افتحي `pins` واحذفي سطر الاسم، وبعدها يقدر ينشئ رمز جديد.
- بعد ٥ محاولات غلط ينقفل الحساب ١٠ دقايق.
